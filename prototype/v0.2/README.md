# V0.2 静态交互原型

这是 Prompt Studio CN 的 **产品/UI 原型**，用于验证信息架构、页面关系、Prompt Builder 交互和本地资产概念。

## 可演示能力
- 图片 / 视频 / 3D / 音频 Builder
- 模板载入与模型选择
- 效果图 / Ref A-D 插入
- LocalStorage 资产保存
- JSON 导入 / 导出 / 分享码
- 工作流页面概念展示

## 明确不代表正式实现
- 不是真实 AI 模型调用层
- 不是真实节点工作流引擎
- 不适合大规模图片、视频持久化
- LocalStorage 仅用于原型验证

正式开发请从 `/docs` 与 `/apps` 开始，不要继续在本目录堆叠生产功能。
