# 产品愿景

## 一句话

**把“AI 创作方法”变成可理解、可复用、可运行、可分享的本地资产。**

## 为什么不是普通 Prompt Library

普通 Prompt Library 主要解决“找到一段文字并复制”。Prompt Studio 要解决的是：

`看到效果 → 理解参数 → 调整模板 → 组合 Prompt → 绑定参考素材 → 执行工作流 → 保存输出 → 形成新资产 → 分享/Fork`

因此 Prompt 只是 Creation Asset 的一个组成部分。

## 核心原则

1. **Local-first**：用户创作素材和敏感参考默认不离开设备。
2. **Visual-first**：效果图/视频是学习 Prompt 最直接的入口。
3. **Structured**：Prompt 由可理解的参数、变量和片段组成，而不是一整块黑盒文字。
4. **Multimodal**：图片、视频、3D、音频使用共享资产模型，但拥有各自专用参数。
5. **Workflow-aware**：记录如何生成，而不仅记录生成了什么。
6. **Forkable**：优质创作方法可以复制、修改、版本化和分享。

## 目标用户

- AI 图片 / 视频创作者
- 角色与视觉设定工作流用户
- ComfyUI / 本地生成用户
- 需要积累大量 Prompt 与案例的高级用户
- 小型创作团队

## 产品边界

### 做
- Prompt Builder
- 模板与参数系统
- Creation Asset 管理
- 图片/视频案例与参考素材
- Workflow 编排与外部工作流适配
- 本地搜索、标签、版本
- Share Pack / Fork

### 暂不做
- V1.0 前不建设完整社交网络
- 不自研基础生成模型
- 不把所有第三方模型 API 做成强依赖
- 不把用户私有素材默认上传云端
