# 竞品研究框架

本文件不追求简单罗列网站，而是记录“可以借鉴什么、不要复制什么”。

## Promptomania
重点：视觉化 Prompt Builder、按模型/用途组织入口。  
启发：参数选项最好配效果缩略图，而不是只给术语。  
我们的扩展：本地资产、视频专用结构、Workflow、版本和 Pack。

## Krea / Nodes 类产品
重点：创作工作台 + 节点工作流。  
启发：Prompt 可以进入图形化 pipeline，而非停留在表单。

## ComfyUI
重点：可复现 Workflow、节点生态、本地执行。  
启发：Workflow 与输出必须可回溯；但 Prompt Studio 的核心对象保持厂商中立。

## PromptBase / PromptHero / FlowGPT
重点：发现、封面、标签、作者、Fork/交易/社区。  
启发：社区阶段“看效果 → Fork”比纯文本列表更自然。

## Langfuse / Promptfoo
重点：版本、变量、多模型、评估。  
启发：高级 Prompt 管理需要版本和 Variant，而不是覆盖旧文本。

## 研究原则
- 复刻交互模式，不复制品牌、Logo、版权素材与原文案。
- 每次竞品调研最终要落到一个明确产品决策或“不做”的判断。
